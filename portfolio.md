## 5. Projects

### Basic Content Agentic AI

**Production-grade agentic workflow · n8n · Groq · Supabase · Gmail** · [View on GitHub](https://github.com/faisalmrasul/Inquiro-Basic_Content_Agentic-AI) · [Full write-up →](/inquiro-media/projects/)

A sophisticated agentic AI workflow that autonomously researches, drafts, self-critiques, and delivers professional content reports via formatted HTML email — triggered by a single webhook call. The system collapses a multi-step content pipeline (research → write → review → deliver) into one automated sequence, achieving an estimated **87% reduction** in content operation time.

**Architecture highlights:**
- **Persistent memory** via Supabase — user profile and conversation history maintained across sessions
- **Intelligent routing** — LLM planner decides whether to invoke live web search (SerpAPI) or process provided content directly
- **Self-critique layer** — a dedicated Critic Agent scores output quality and triggers revision if below threshold before delivery
- **Professional email delivery** — HTML-formatted output with quality badges and metadata sent via Gmail OAuth2

**Tech stack:** n8n · Groq (Llama-3.3-70b) · Supabase · SerpAPI · Gmail OAuth2

**What this demonstrates:** The shift from building individual automations to designing systems with embedded governance — treating output quality as a first-class production concern.
